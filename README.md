# Число · Math4Class

**Математика с интересом для 1–4 классов.** Рабочее название проекта — «Число».
Концептуальная основа — [«Слово»](https://artignat2000.github.io/slovo2/): короткие занятия,
объяснение перед практикой, бережная работа с ошибками, личный прогресс и офлайн-доступ.

Это работающий движок с сохранённым архивным банком из 301 задания. После поштучной сверки с повторно присланными фотографиями страниц 46–47 учебника **М. И. Моро и соавторов, «Школа России», 4 класс, часть 1, Просвещение, 2026** детям доступны только **23 задания в 6 темах 4 класса**. Остальные 278 заданий, включая демо 1–3 классов, варианты по мотивам страниц и темы только из оглавления, скрыты: совпадение темы или таблицы с учебником не подтверждает конкретное условие. История и сохранённые данные не удалены; старые незавершённые занятия с неподтверждёнными заданиями не открываются.

[Реестр сверки →](docs/SOURCE_AUDIT.md) · [Правила и их статусы →](docs/PRODUCT_RULES.md). Фотографии учебника не публикуются; это не официальное приложение издательства.

## Быстрый старт

Нужен **Node.js ≥ 22.17** и npm.

```bash
npm ci
npm run dev          # http://localhost:5173, сервер слушает 0.0.0.0
npm run check        # TypeScript, проверка контента, unit/UI-тесты, production-сборка
npm run test:e2e     # сборка + браузерные сценарии, офлайн-PWA, WCAG AA, адаптивность
npm run test:e2e:built -- tests/e2e/equation-pilot.spec.ts # целевой тест существующей сборки
npm run preview     # production-сборка на http://localhost:4173
```

Браузер для тестов включён в dev-зависимость `@sparticuz/chromium` — отдельная загрузка
Chromium не нужна. Браузерные тесты рассчитаны на Linux x64. На другой платформе можно
заменить `launchOptions` в `playwright.config.ts` на обычный установленный Playwright Chromium.

## Что работает

- Выбор 1–4 класса, каталог по разделам учебника, поиск по темам/страницам и фильтры по источникам. Показываются только задания, сверенные с учебником.
- Объяснение с примером перед занятием, обычно 5 заданий без таймера.
- **Числовой ответ, выбор варианта, сравнение, порядок элементов и деление с остатком**.
- В делении — отдельные поля для неполного частного и остатка, проверка обоих значений.
- Числа с пробелами в разрядах, десятичной запятой; схемы прямоугольника, долей круга и квадрата с равными треугольниками.
- Подсказки и объяснение каждого ответа. Ошибка возвращается в конце занятия **один раз**.
- Сохранение незавершённого урока, включая проверенный ответ, подсказку и очередь повторов.
- Три ступени освоения; продвижение не чаще раза в день, повторения через 1/3/7 дней.
- Дневная цель, история, недельная активность, серии занятий, звёзды, опыт и 6 наград.
- До 12 независимых профилей детей на устройстве.
- Раздел для взрослых: цели, уменьшение движения, импорт тем, экспорт/восстановление данных.
- Валидация JSON до импорта, подтверждение замены, локальная предыдущая копия и предупреждение при ошибке записи.
- Установка как PWA, работа опубликованной версии офлайн, явное предложение обновления **вне занятия**.
- Адаптивный интерфейс, клавиатура, фокус в диалогах, reduced motion, локальный кириллический шрифт.

## Автору учебных материалов

Начать можно **не с JSON**, а с обычного документа. Для каждой темы нужны:

1. Название и конкретное умение, которое тренируем.
2. Короткое объяснение и один разобранный пример.
3. Задания с верными ответами.
4. Подсказка и понятное объяснение решения **к каждому заданию**.
5. Типичные ошибки и желаемый порядок тем.

[Инструкция и формат пакета → `docs/CONTENT.md`](docs/CONTENT.md)

Рабочий файл: [`public/content/example-grade-4.json`](public/content/example-grade-4.json).
Его можно скачать и из раздела **«Родителям → Учебные материалы»**.

```bash
npm run content:check -- path/to/my-grade-4.json
```

Подключение: **«Родителям → Загрузить пакет тем»** (на текущем устройстве) или замена
`src/content/grade-4.json` и публикация новой сборки (для всех пользователей).

## Хранение и ограничения

Без сервера, регистрации, рекламы, внешних шрифтов и аналитики. Данные находятся в
**localStorage этого браузера**, предыдущая валидная запись хранится отдельно. Это не облачная
резервная копия: очистка браузера удаляет обе. Перенос между устройствами — через JSON-файл.
При запрете или переполнении хранилища приложение продолжает работать в памяти и показывает
предупреждение. **Не закрывайте такую вкладку до экспорта данных.**

Импорт: пакет тем до 1 МБ; копия до 5 МБ; суммарные импортируемые данные до 2 МБ.
Это оставляет место для локальной предыдущей копии. Пока нет синхронизации, кабинета учителя,
генерации вариантов, рукописного ввода, интерактивного заполнения столбиков и произвольного ввода дробей вида `a/b`.
Приложение не вычисляет код или выражения из учебного JSON.

## Публикация

`.github/workflows/deploy.yml` собирает и публикует **main** на GitHub Pages после проверок.
В настройках репозитория нужно выбрать **Pages → Source → GitHub Actions**.
Ветка разработки сама по себе сайт не обновляет. Сборка с относительной базой работает
как в `/Math4Class/`, так и в корне сайта. History fallback хостингу не нужен: маршруты в hash.

PWA включается только в production. Для установки нужен HTTPS или localhost.
Обновление не перезагружает активное занятие без участия пользователя.

`npm audit --omit=dev` проверяет зависимости приложения. У текущего Workbox-инструментария
есть транзитивные advisory в dev-зависимостях; они не исполняются в браузере. Не стоит
применять `npm audit fix --force` без проверки совместимости сборщика и PWA.
