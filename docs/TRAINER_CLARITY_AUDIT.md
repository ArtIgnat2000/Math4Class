# Проверка понятности доступных тренажёров

7 ноября 2026, по запросу владельца после экрана «Площадь частей». Область проверки — **14 обучающих тренажёров семи уже открытых тем**: цель, исходные данные, ближайшее действие без раскрытия «Справки», реакция на ответ и продолжение. Это проверка интерфейса и кода, не наблюдение ребёнка. Отдельные утверждённые проверочные задания и скрытый архив не изменялись; полнота всех материалов учебников этой проверкой не подтверждается.

| Тема                   | Тренажёр        | Что ребёнок видит / результат проверки                                                                                                                      |
| ---------------------- | --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Площадь                | Найди часть     | Вопрос про выделенный треугольник, четыре равные части, площадь всего квадрата, выбор ответа; обратная связь объясняет деление. Добавлено.                  |
| Площадь                | Собери половину | Цель, выбор двух названных частей, «Готово», повторное нажатие убирает часть; количество видно, названия выделенных частей доступны скринридеру. Добавлено. |
| Уравнения              | Найди число     | Уравнение, схема, вопрос «Чему равен x?» и действие «Нажми число» уже были видимы.                                                                          |
| Уравнения              | Собери решение  | Цель была видна; добавлен порядок нажатия: уравнение → действие → значение x.                                                                               |
| Степени десяти         | Найди результат | Пример и варианты уже видны; добавлено «Вычисли и нажми ответ».                                                                                             |
| Степени десяти         | Собери число    | Добавлены цель собрать число из разрядов и порядок выбора цифр; текущий разряд и табло остаются видимыми.                                                   |
| Вычисления по разрядам | Найди результат | Тот же компонент: пример, варианты и добавленное действие.                                                                                                  |
| Вычисления по разрядам | Собери число    | Тот же компонент: цель, порядок выбора, текущий разряд и табло.                                                                                             |
| Деление с остатком     | Найди делимое   | Добавлено, что нужно сосчитать предметы в группах и остаток и нажать ответ.                                                                                 |
| Деление с остатком     | Собери остаток  | Ранее добавлены цель, целевой и текущий остаток, действия «+ 1», «− 1» и «Готово»; оставлены без изменений.                                                 |
| Годы и месяцы          | Собери год      | Добавлена видимая цель — расставить месяцы по порядку на круге; строка состояния по-прежнему объясняет перенос и нажатия.                                   |
| Годы и месяцы          | Считаем месяцы  | Вопрос «Сколько месяцев вместе?», круги с 12 месяцами и действие «Нажми число месяцев» уже видны.                                                           |
| Римские цифры          | Римские часы    | Добавлена видимая цель найти на круге римскую запись числа в центре; способы действия остаются в строке состояния.                                          |
| Римские цифры          | Собери число    | Уточнено, что число надо записать римскими цифрами; табло и строка состояния показывают действие.                                                           |

Для площади проверяются неверный и верный ответ, подсказка, оба раунда, выбор и отмена частей, клавиатура, доступные имена, отсутствие записи прогресса и четыре размера 320/390/768/820 px. Контракт целей и действий всех 14 тренажёров проверяется `tests/trainer-clarity.test.tsx`; геометрия и пути площади — `tests/e2e/area-trainer-clarity.spec.ts`. Автотесты не доказывают понятность для ребёнка; детская проба и реальный Safari остаются необходимы.
