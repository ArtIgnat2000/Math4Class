# Сторонние компоненты

Приложение использует React / React DOM, Vite, TypeScript, Zod, Lucide, Vite PWA / Workbox.
Версии и полный список зафиксированы в `package-lock.json`; условия лицензирования — в пакетах.
Lucide — ISC. React, Zod и большая часть инфраструктуры — MIT. Workbox — MIT.

Шрифт **Manrope**, автор Mikhail Sharanda, поставляется локально через `@fontsource-variable/manrope`,
SIL Open Font License 1.1. Текст лицензии включён в публикацию:
`public/licenses/Manrope-OFL.txt`. Внешних запросов к Google Fonts нет.

Логотип, иконки приложения и SVG-иллюстрация математического кубика созданы для этого проекта.
Для помощника Бука используются два кадра из 3D-спрайтов проекта автора
[«Слово»](https://github.com/ArtIgnat2000/slovo2):
`public/buk3d/student/face.webp` и `public/buk3d/student/happy.webp` (первые кадры,
обрезаны до 256 × 256). Копии хранятся локально в `public/illustrations/buk/` для
работы офлайн. Код «Слова» не копировался. Иллюстрация со слоном удалена.
