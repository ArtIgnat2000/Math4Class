## 1. Полный содержательный пакет 4 класса — следующий этап

- Автор утверждает список тем, порядок и границы навыков.
- По шаблону из CONTENT.md готовим объяснения, примеры, задания, подсказки и разбор.
- Проходим новые настоящие темы с ребёнком на телефоне, затем расширяем покрытие.
- Проверяем, где приходится читать слишком много, какие ошибки движок должен различать.
- После авторского/методического утверждения заменяем вводные темы 4 класса или оставляем их отдельным знакомством. Остальные классы пока демонстрационные.

**Готово к публикации**, когда проверены ответы, единицы и объяснения, пройдены автоматические
проверки и проведён хотя бы один реальный пользовательский прогон. Не называем курс полным
по одному лишь количеству карточек.

## 2. Расширение математических типов — по реальным материалам

Не добавлять все виджеты заранее. Выбрать нужные по заданиям автора:

- несколько полей для промежуточных шагов (пара «частное + остаток» уже есть);
- пошаговый поиск неизвестного / пропущенного числа (числовой ответ на уравнения уже есть);
- дробь как числитель и знаменатель, эквивалентность дробей;
- пошаговое решение задачи с отдельной проверкой шага;
- интерактивное заполнение столбиков (письменные алгоритмы уже объясняются текстом);
- числовая прямая, таблицы, часы, больше схем;
- контролируемая генерация вариантов по безопасным шаблонам и seed, без eval.

Каждый новый тип: контракт → валидатор → чистая проверка → доступный рендерер → образец → тесты.
Версия формата повышается, если изменение ломает старые пакеты.

## 3. Планирование и педагогика

- Выделение тегов навыков и предпосылок без жёстких замков.
- Входная диагностика — только после методической проработки.
- Более точный планировщик по независимым успешным попыткам, подсказкам и давности.
- Перемежение разных навыков, а не только одна тема за занятие.
- Проверка качества отвлекающих вариантов и объяснений типичных ошибок.

Не смешивать интерес ребёнка, количество кликов и знание темы в один «магический рейтинг».

## 4. Надёжность и взрослые

- IndexedDB с миграцией существующего прогресса, восстановлением и тестами отказов.
- Небольшой редактор материалов с предпросмотром, если JSON станет неудобен автору.
- Экспорт понятного отчёта, задания от взрослого, несколько целей по темам.
- Синхронизация устройств — отдельный проект: сначала модель аккаунтов, согласия,
  конфиденциальность детских данных, восстановление и стоимость эксплуатации.

## 5. Программы 1–3 классов

Та же схема движка, отдельные проверенные наборы и возрастная адаптация формулировок.
Для 1 класса особенно важно проверить самостоятельное чтение, размер целей и потребность
в озвучивании. Не считать, что простая смена чисел делает задание подходящим первокласснику.
