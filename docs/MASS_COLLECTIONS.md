# Коллекции предметов для единиц массы — проектирование

## Учебное правило важнее оформления

Каждая коллекция — **полный независимый набор** из четырёх номиналов: `1 г`, `1 кг`, `1 ц`, `1 т`. Грамм — маленькая аптечная гирька; килограмм — спортивная гиря; центнер — ящик/мешок **с грузом**; тонна — контейнер/машина **с грузом**. Цвета и материалы могут объединять коллекцию, но силуэт и подпись каждой единицы обязаны отличаться. Масса пустого ящика, контейнера или автомобиля не утверждается. Для неизвестной массы нужен отдельный предмет **без номинала**. Одной и той же изображённой гире нельзя менять числовую надпись CSS-фильтром.

В рамках одной учебной сцены используем **только одну активную коллекцию**: не перемешиваем её с предметами другой. Исключение — сопоставление разных _номиналов_ внутри той же коллекции. Если картинка мала, читаемая подпись под предметом обязательна; важные числа не размещать поверх сложной фактуры.

## Шесть направлений без логотипов и копирования чужих изделий

| Код (проектный) | Оригинальный визуальный язык                            | Отличие номиналов                                                                          |
| --------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `atelier`       | Светлая кожа, металл, седельная строчка; конный мотив   | Аптечная латунь → кожаная гиря → кожаный дорожный короб → крупный грузовой кузов           |
| `forged`        | Чернёный металл, тонкие золотые прожилки ремонта        | Точная гирька → кованая гиря → большой кованый ящик → грузовой контейнер                   |
| `studio`        | Матовый анодированный металл, стекло и мягкая подсветка | Миниатюра → спортивная гиря → техноящик → технологический контейнер                        |
| `grand-tour`    | Лакированное дерево, тёплая латунь, ручная работа       | Аптечная гиря → гиря с деревянными вставками → деревянный грузовой сундук → грузовой вагон |
| `mineral`       | Тёмный камень и светлые минеральные прожилки            | Малый цилиндр → гиря → каменный грузовой ящик → тяжёлый грузовой модуль                    |
| `porcelain`     | Светлый фарфор и кобальтовая геометрия                  | Точная гирька → защищённая гиря → грузовой короб → крупный контейнер                       |

Это **дизайн-направления**, а не уже созданные шесть полных наборов. До выпуска каждого нужны четыре предметных ассета + неизвестная масса, проверка номиналов на телефоне и проверка с детьми, что внешний вид не мешает узнавать единицы. Текущие изображения из разных направлений пока служат пилотом урока, а не продаваемой «коллекцией».

## Кристаллы — отдельное решение

Не вводим покупку, дефицит или награды в детский урок до согласования с владельцем продукта. Если коллекции позже открываются за кристаллы, выбор и покупка должны быть в зоне взрослого; все математические темы и подсказки остаются доступны без оформления. Нужны отдельные решения о происхождении кристаллов, цене/валюте, офлайн-доступе, сохранении выбора и возрастных ограничениях. Сначала проверяем учебный смысл коллекций, затем проектируем экономику и интерфейс.
