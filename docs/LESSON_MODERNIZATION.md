# Модернизация существующих уроков

Рабочий план, 7 ноября 2026. Готовность по отдельной теме подтверждается проверками [стандарта урока](LESSON_STANDARD.md) и детской пробой, а не самим наличием в каталоге. Здесь перечислены темы, доступные по текущему фильтру источников; скрытый банк сохраняется и не открывается до поштучной сверки.

Порядок дальнейшей работы: выбрать одну доступную тему → составить ТЗ по [рабочему маршруту](LESSON_WORKFLOW.md), включая осмысленные разные механики → реализовать и проверить сценарии, мобильную компоновку, доступность и отсутствие утечек → обновить отчёт по источникам и результаты → перейти к следующей. Не добавлять непроверенные задания и не менять стабильные ID или сохранённый прогресс. Текущая статистика наличия сверенных задач не доказывает полного охвата ни упражнения, ни страницы: см. [отчёт охвата](TEXTBOOK_COVERAGE_REPORT.md).

Для полного охвата всех учебников нужны сами согласованные материалы и ручная сверка теории, каждого номера и его частей. По решению владельца от 7 ноября 2026 модернизация пяти уже доступных тем разрешена до детской пробы; PR остаётся черновым до неё и проверки на реальном Safari. Для новых тем продолжает действовать PILOT-01. Любой блокирующий конфликт разрешается по ASK-01; технические тесты не заменяют наблюдение ребёнка.
