# Материалы: договорённость автора и движка

> Импорт сохраняет пакет локально, но не делает его задания видимыми детям без поштучной сверки с утверждённым учебником. См. [реестр](SOURCE_AUDIT.md).

## С чего начать содержательную работу

Можно подготовить материал обычным текстом или таблицей — перевод в JSON не должен мешать
методической работе. Для каждой небольшой темы заполните карточку:

| Поле                 | Что подготовить                                    |
| -------------------- | -------------------------------------------------- |
| Класс и раздел       | Например: 4 класс, величины                        |
| Название             | Одно конкретное умение: «Переводим часы в минуты»  |
| Результат            | Что ребёнок сможет сделать сам после занятий       |
| Уже нужно знать      | Необязательные методические предпосылки            |
| Объяснение           | 2–5 коротких предложений, одно правило за раз      |
| Разобранный пример   | Действия и почему они нужны                        |
| Банк заданий         | Для начала 5–10; лучше разные числа и формулировки |
| Верные ответы        | Точное число, ID варианта, знак или порядок        |
| Подсказка к каждому  | Следующий полезный шаг, не просто повтор вопроса   |
| Объяснение к каждому | Понятный путь к верному ответу                     |
| Типичные ошибки      | Что перепутают и как это бережно объяснить         |

Первые материалы 4 класса можно разложить по содержательным линиям: числа и разряды,
действия, величины, геометрия, задачи. **Окончательный список и порядок — за автором.**
В 4 классе уже добавлены 27 узких тем по фотографиям учебника «Школа России»;
[карта покрытия](SCHOOL_RUSSIA.md) отделяет страницы 46–47 от названий из оглавления.
Сохранённые 8 широких вводных демо-тем не являются утверждённым планом курса.

## Как подключать

### На одном устройстве, без сборки

1. Скачайте [`example-grade-4.json`](../public/content/example-grade-4.json).
2. Замените название, объяснения и задания. Поставьте `isDemo: false` для своего набора.
3. Проверьте: `npm run content:check -- ./my-grade-4.json`.
4. В приложении: **Родителям → Учебные материалы → Загрузить пакет тем**.
5. Посмотрите итог проверки и подтвердите замену.

**Импорт заменяет весь пакет выбранного класса, а не добавляет отдельные темы к старому.**
Поэтому собирайте в одном файле все актуальные темы класса. Остальные классы не меняются.
Файл — UTF-8 JSON до 1 МБ; содержимое не отправляется на сервер.

### Для всех пользователей сайта

Замените соответствующий `src/content/grade-4.json` (или другой класс), выполните `npm run check`,
проверьте занятия, затем опубликуйте новую сборку. Встроенные пакеты входят в офлайн-кэш.
Пользовательский импорт на конкретном устройстве имеет приоритет над встроенным пакетом;
вернуться к встроенному можно в разделе материалов у взрослых.

## Оболочка пакета

```json
{
  "version": 1,
  "grade": 4,
  "isDemo": false,
  "title": "Математика · 4 класс",
  "topics": []
}
```

В настоящем файле `topics` содержит **от 1 до 60 тем**. Пустой массив выше — только схема оболочки.
`version` — версия формата, не номер обновления материала; сейчас всегда `1`.
`grade` — число `1`, `2`, `3` или `4`.

Структурная [JSON Schema](../public/content/schema.json) помогает редактору подсказывать поля.
Для файлов проекта подключена настройка VS Code. Авторитетная проверка — `parsePack` из
`src/engine/content.ts`: она дополнительно проверяет связи и уникальность ID, чего JSON Schema
целиком не выражает. После изменения контракта: `npm run content:schema`.

## Тема

```json
{
  "id": "hours-to-minutes",
  "title": "Часы и минуты",
  "description": "Учимся переводить часы в минуты",
  "category": "quantities",
  "color": "blue",
  "symbol": "ruler",
  "minutes": 5,
  "lessonSize": 5,
  "theory": {
    "title": "Один час — это 60 минут",
    "text": "Чтобы перевести часы в минуты, умножь количество часов на 60.",
    "example": "2 часа = 2 × 60 = 120 минут."
  },
  "tasks": []
}
```

`tasks` должен содержать **от 1 до 200 заданий**; в этом фрагменте массив пуст только для компактности.
Урок выбирает до `lessonSize` разных заданий из банка. Если заданий меньше, урок короче.
`lessonSize`: 1–10, по умолчанию 5; `minutes`: подсказка по длительности, не таймер.
В повторении сначала выбираются задания, которые раньше вызвали затруднение.

| Поле       | Допустимые значения                                                                     |
| ---------- | --------------------------------------------------------------------------------------- |
| `category` | `numbers` (числа, в том числе доли), `operations`, `quantities`, `geometry`, `problems` |
| `color`    | `sage`, `peach`, `lavender`, `blue`, `butter`                                           |
| `symbol`   | `numbers`, `plus`, `multiply`, `ruler`, `shapes`, `fraction`, `puzzle`, `brackets`      |

Название темы до 80 символов, описание до 180. Текст — обычный, **не HTML, Markdown или LaTeX**.
Можно использовать Unicode: `×`, `−`, `:`, `²`, `°`. Правила, вопросы, подсказки и объяснения
обязательны. Неизвестные поля отклоняются, чтобы опечатки не игнорировались незаметно.

## Общие поля задания

- `id` — стабильный ID внутри темы.
- `type` — один из пяти типов ниже.
- `question` — вопрос обычными словами.
- `hint` — помощь **до ответа**.
- `explanation` — разбор **после ответа**.
- `expression` — необязательное выражение для крупного показа, **без `=` и `?`**;
  интерфейс добавит `= ?`. Обычно применяется к числовому заданию.
- `diagram` — необязательная схема, см. ниже.

### 1. Числовой ответ — `number`

```json
{
  "id": "two-hours",
  "type": "number",
  "question": "Сколько минут в двух часах?",
  "answer": 120,
  "unit": "мин",
  "hint": "В каждом часе 60 минут. Возьми 60 два раза.",
  "explanation": "2 × 60 = 120 минут."
}
```

`answer` — **число в JSON**, не строка. `unit` показывается рядом с полем, ребёнку не нужно её писать.
Принимаются `12 000`, неразрывные пробелы, десятичные `1,5` и `1.5`, знак `−`.
Не принимаются единицы внутри ответа, формулы `2+3`, научная запись `1e3` и дроби `1/2`.
По умолчанию сравнение с точностью `1e-9`; при необходимости есть числовое поле `tolerance` (0–1).
Для долей пока используйте выбор варианта, сравнение или десятичный числовой результат.

### 2. Выбор одного варианта — `choice`

```json
{
  "id": "three-hours",
  "type": "choice",
  "question": "Сколько минут в 3 часах?",
  "options": [
    { "id": "a", "label": "120 минут" },
    { "id": "b", "label": "180 минут" },
    { "id": "c", "label": "300 минут" }
  ],
  "answer": "b",
  "hint": "Умножь 60 на 3.",
  "explanation": "60 × 3 = 180 минут."
}
```

2–8 вариантов. Ответ — **ID**, не номер позиции и не текст. Верный вариант обязан существовать.
Варианты пока показываются в авторском порядке; банк заданий перемешивается.

### 3. Сравнение — `compare`

```json
{
  "id": "compare-time",
  "type": "compare",
  "question": "Сравни время.",
  "left": "2 часа",
  "right": "100 минут",
  "answer": ">",
  "hint": "Сначала вырази обе величины в минутах.",
  "explanation": "2 часа — это 120 минут, а 120 больше 100."
}
```

Ответ — строго `<`, `=` или `>`. `left` и `right` — отображаемые строки.
**Движок их не вычисляет**: автор отвечает за смысл и верный знак.

### 4. Порядок элементов — `order`

```json
{
  "id": "order-time",
  "type": "order",
  "question": "Расположи от меньшего времени к большему.",
  "items": [
    { "id": "a", "label": "30 минут" },
    { "id": "b", "label": "1 час" },
    { "id": "c", "label": "90 минут" }
  ],
  "answer": ["a", "b", "c"],
  "hint": "Один час — это 60 минут.",
  "explanation": "30 < 60 < 90, поэтому: 30 минут, 1 час, 90 минут."
}
```

2–8 элементов. `answer` содержит **все ID ровно один раз**. Начальный порядок перемешивается
и никогда не совпадает с ответом целиком. Элементы перемещаются кнопками-стрелками —
задание работает и с клавиатурой, не требует drag-and-drop.

### 5. Деление с остатком — `division`

```json
{
  "id": "divide-74-by-8",
  "type": "division",
  "question": "Найди неполное частное и остаток.",
  "dividend": 74,
  "divisor": 8,
  "answer": { "quotient": 9, "remainder": 2 },
  "hint": "Найди самое большое число, кратное 8 и не большее 74.",
  "explanation": "8 × 9 + 2 = 74. Остаток 2 меньше делителя 8."
}
```

Ребёнок заполняет **два подписанных поля**. `dividend` — целое 0–1 000 000,
`divisor` — целое 1–1 000 000. Обе части `answer` — неотрицательные целые до 1 000 000.
Валидатор проверяет равенство `divisor × quotient + remainder = dividend` и условие
`remainder < divisor`. Просто совпадения равенства недостаточно!

Допустимы нулевое неполное частное и нулевой остаток. Если остатка нет, ребёнок вводит `0`,
не оставляет поле пустым. В сохранённой попытке обе части — строки (как у числового ввода),
в учебном JSON — **числа**. Обе части проверяются вместе, повтор и освоение считаются за
одно задание. Можно использовать пробелы в больших целых числах.

## Три схемы, которые уже поддерживаются

Прямоугольник (к любому типу задания):

```json
{ "type": "rectangle", "widthLabel": "8 см", "heightLabel": "5 см" }
```

Показывает стороны и их подписи. Схема условная, **не чертёж в масштабе**.

Доли круга:

```json
{ "type": "fraction", "parts": 8, "shaded": 3 }
```

От 2 до 12 равных частей; закрашенных от 0 до `parts`.
Квадрат, разделённый на равные треугольники:

```json
{ "type": "square-parts", "sideLabel": "8 см", "parts": 4 }
```

`parts` — только `2` или `4`. Рисуется настоящий квадрат: одна диагональ для двух частей,
две диагонали для четырёх. `sideLabel` — подпись стороны; автор задаёт её и математический
ответ согласованно. Площадь части — квадрат стороны, делённый на число частей, не длина стороны.

Эти объекты используются как значение `diagram` внутри задания.

## Учебник, разделы и источники — необязательные поля v1

Старые пакеты без этих полей продолжают работать. Для привязки к учебнику пакет может содержать:

- `curriculum`: `series`, `title`, `authors` (массив строк), `publisher`, `year`, `part`,
  необязательное `edition` и обязательное `coverage` — честное описание границ материала.
  Эти данные показываются на главной, в каталоге и в окне об источниках.
- `sections`: массив объектов `{ "id": "mass", "title": "Единицы массы", "topicIds": ["kg-to-g"] }`.
  Можно добавить `description`. Если разделы заданы, **каждая тема должна входить ровно в один**;
  неизвестные ID тем, повторённые ID разделов и повторённое членство отклоняются.

Дополнительные поля темы:

- `reference`: например `{ "kind": "page", "pages": [46], "exercises": [218] }`.
  `page` — тема видна на присланной странице; `contents` — известно только название из оглавления;
  `intro` — вводная тема, для неё допустимо `pages: []`. Для первых двух нужен хотя бы один номер.
  Для `contents` в `pages` указываются **целевые страницы из оглавления**, а не страница самого оглавления.
  `exercises` — связь с тематикой упражнения, не обещание точного воспроизведения его условий.
- `isDemo: true` — демо-тема внутри в остальном содержательного пакета.
- `challenge: true` — показывает «Задача со звёздочкой», не закрывает доступ.

Номер страницы, источник и сложность видны в карточке и перед началом занятия. В каталоге есть
группировка и фильтры по разделу/источнику; поиск также понимает номера страниц и упражнений.
Полный пример метаданных и разделов — `src/content/grade-4.json`.

## ID и сохранение прогресса

ID содержат строчные латинские буквы, цифры, `-`, `_`; начинаются буквой или цифрой.
Максимум 80 символов. ID темы уникален в классе, ID задания — в теме, ID вариантов — в задании.

- Исправили опечатку или объяснение — **сохраняем ID**.
- Добавили задания в тот же навык — старые ID сохраняем, новым даём новые.
- Совсем другое умение — **новый ID темы**.
- Удалённые темы исчезают из каталога, но их история не стирается.
- Уже начатое занятие хранит снимок заданий: обновление пакета его не ломает.

Ключ прогресса — `класс:ID-темы`. Материалы одинаковых ID из разных классов не конфликтуют.
Профили детей независимы. Переименование ID без миграции начнёт для темы новый прогресс.

## Методическая проверка перед публикацией

Автоматическая валидация проверяет **формат** и арифметическую согласованность `division`,
но не решает остальные текстовые задачи вместо автора. Отдельные тесты проверяют арифметику,
подстановки в уравнения, календарь, сравнение масс, площади и логику нового встроенного банка.

- Все числовые ответы и знаки проверены вручную.
- В вариантах нет двух разных записей одного и того же верного ответа.
- Все элементы порядка действительно имеют однозначный порядок.
- Единицы верны: см и см² не взаимозаменяемы.
- Подсказка предлагает действие, а объяснение объясняет, почему ответ верный.
- Формулировка понятна без картинки, кроме явно обозначенных заданий на схему.
- Задание соответствует конкретному возрасту и изученным способам.
- Материал проверен и на телефоне, и с клавиатуры.
- Демопак не объявляется полным учебным курсом.
