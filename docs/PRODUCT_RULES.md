# Правила содержания и детского интерфейса

Это редактируемый реестр решений владельца. Изменения проходят через PR; владелец может в чате попросить изменить, приостановить или отменить правило. Для временного отключения укажите срок/условие возврата. При противоречии не выбирать молча: показать конфликтующие ID, предложить вариант (по умолчанию безопасность и проверяемость источника выше полноты каталога) и спросить владельца. Не менять правила через детский интерфейс.

| ID        | Состояние | Правило                                                                                                                                                                                                                                                                | Как проверить                                                                                                                                                      |
| --------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| SOURCE-01 | действует | Детям показывать только задания, конкретные условия которых сверены с утверждёнными страницами реального учебника. Название темы, совпадение с программой и `reference.pages` не являются подтверждением задания. Непроверенное скрывать, не удаляя данные и прогресс. | Для каждого видимого задания указаны издание, страница, номер/фрагмент и результат сверки; непроверенные недоступны в каталоге, рекомендации и сохранённой сессии. |
| SOURCE-02 | действует | Для присланного скана сначала подтвердить выходные данные; найденный онлайн учебник нельзя использовать, пока владелец не подтвердил точное издание (авторы, класс, часть, год/издание и страницы). Не распространять сканы или неразрешённые копии страниц.           | Реестр источников содержит явное согласование владельца и точную привязку задания.                                                                                 |

Обучение и проверка должны быть доступны раздельно, без автоматического перехода к проверке.                                                                                        | Ребёнок может изучить схему и вернуться к ней без запуска задания.                                                                                                 |

Не дублировать показатели, не писать мелкие поучения.                                                                                       | На телефоне главное понятно без чтения длинного абзаца и прокрутки.                                                                                                |

## Текущий статус источников

4 ноября 2026 владелец повторно прислал обложку и фото страниц 46–47 учебника Моро (4 класс, часть 1, Просвещение, 2026; 16-е стереотипное издание). [Поштучный аудит](SOURCE_AUDIT.md) фиксирует 23 непосредственно сверенных условия из 301 сохранённого задания. Только они доступны детям; остальные 278 скрыты, но банк и история прогресса не удалены. Таблицы учебника используются для объяснения, а не для выдумывания новых проверочных вопросов. Страницы 76–82 известны только по оглавлению: они не включены. Скачанный из Интернета учебник не использован.
